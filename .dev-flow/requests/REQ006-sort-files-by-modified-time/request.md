# REQ006 文件按修改时间倒序排列

## 目标

所有文件夹下的文件统一按修改时间从新到旧排列，最新修改的文件显示在最前面。

## 范围

- server/library.mjs 的索引排序规则及 tests/library.test.mjs 回归测试。

## 非目标

- 不改变文件夹节点的名称排序；不移除用户主动选择的标题或类型排序；不执行浏览器前端验收。

## 验收条件

- AC-1: 同一文件夹下的文件按 mtimeMs 降序输出，最新修改文件位于最前。
- AC-2: 该规则由统一索引结果驱动，适用于根目录及所有层级文件夹；相同修改时间使用 metadata order 和标题进行确定性兜底。
- AC-3: 文件夹节点仍按名称排列，现有标题和类型排序选项保持可用。

## 技术方案

- 调整服务端 compareItems：先按 topicPath 分组顺序，再按 mtimeMs 降序，随后以 metadata order 和标题兜底；增加真实文件时间戳回归测试。

## 重要决策

- 无
