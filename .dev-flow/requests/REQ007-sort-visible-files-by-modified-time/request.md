# REQ007 前端文件统一按修改时间倒序

## 目标

目录树中根目录和每层文件夹的文件统一按修改时间从新到旧排列，主文件列表默认也以最新修改优先。

## 范围

- src/App.tsx、新增纯排序模块及对应 Vitest 测试。

## 非目标

- 不修改冻结的 server/**；不改变文件夹节点名称排序；不移除标题或类型排序选项；不执行浏览器前端验收。

## 验收条件

- AC-1: 目录树根目录及每个嵌套文件夹的文件组均按 mtimeMs 降序，最新文件在前。
- AC-2: 主文件列表默认选择最近更新排序；用户主动选择标题、类型或资料库顺序时仍按所选模式展示。
- AC-3: 相同修改时间按标题确定性排序，文件夹节点顺序和后端索引保持不变。

## 技术方案

- 新增纯函数统一处理修改时间比较和 topicPath 分组；LibraryHome 的 filesByTopic 复用该分组函数，sortItems 的 recent 模式复用同一比较函数，并将默认 sortMode 设为 recent。

## 重要决策

- 无
