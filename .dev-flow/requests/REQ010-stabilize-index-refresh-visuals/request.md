# REQ010 稳定索引刷新期间的阅读位置

## 目标

索引更新仅渲染实际变化的目录条目，当前阅读文件未变化时保持内容 DOM 和阅读位置稳定，不出现肉眼可见跳动。

## 范围

- src/App.tsx、新增索引结构共享辅助模块及对应测试；延续既有 Vite 监听隔离和状态轮询。

## 非目标

- 不修改 server 或 library；不改变视觉样式和页面结构；不为关闭后重新打开文件持久化滚动位置。

## 验收条件

- AC-1: 无关文件新增或更新时，当前未变化文件和未变化目录分支保持对象引用；后台索引更新以 transition 应用；当前阅读内容组件在输入不变时跳过渲染；单测和类型检查通过。

## 技术方案

- 合并新旧 LibraryResponse 并复用字段一致的 LibraryItem/LibraryNode；首次加载直接更新，后续刷新用 startTransition；memo 化 ReaderSurface 与 HtmlRichPreview。

## 重要决策

- 通过限制数据和渲染传播范围保持阅读 DOM 原位，不采用刷新后强制写回滚动坐标。
