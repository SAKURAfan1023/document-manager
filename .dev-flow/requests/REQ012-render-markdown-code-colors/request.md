# REQ012 恢复 Markdown 代码块颜色渲染

## 目标

Markdown 预览中的代码块按语言显示清晰的语法颜色，diff 新增行显示绿色，同时保持 Mermaid 图形渲染和现有 Markdown 结构视觉行为不变

## 范围

- Markdown 渲染插件配置、代码块高亮样式、依赖声明与 Markdown 回归测试

## 非目标

- 不改变 Markdown 文档内容、编辑器结构、图形交互、文件刷新逻辑，也不进行浏览器视觉验收

## 验收条件

- AC-1: diff 代码块渲染结果包含可用于绿色新增行和红色删除行的语义高亮标记
- AC-2: JSON 代码块渲染结果包含键、字符串、数值或字面量的语法高亮标记
- AC-3: Mermaid 代码块仍由现有 MermaidDiagram 路径渲染而不被代码高亮器改写

## 技术方案

- 无

## 重要决策

- 无
